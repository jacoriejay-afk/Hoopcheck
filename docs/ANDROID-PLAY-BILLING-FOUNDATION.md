## Read-only verification client
Server-only lib/server/play/verification.ts implements domain-separated HMAC account IDs, short-lived RS256 Google service-account OAuth assertions and the pinned subscriptionsv2.get endpoint. Default off, test-only, exact isolated Supabase host binding, explicit production host rejection, bounded response/deadline, no redirects, generic errors, no raw tokens/credentials returned or logged. No exposed API route or invocation. Synthetic fetch tests do not contact Google. Protected variables: HOOPCHECK_PLAY_VERIFICATION_ENABLED, HOOPCHECK_PLAY_ENVIRONMENT=test, HOOPCHECK_PLAY_ISOLATED_SUPABASE_URL, HOOPCHECK_PLAY_SERVICE_ACCOUNT_EMAIL, HOOPCHECK_PLAY_SERVICE_ACCOUNT_PRIVATE_KEY (PEM), HOOPCHECK_PLAY_ACCOUNT_HMAC_KEY (64 hex characters). Do not set them or rotate an established account-binding key without reviewed acceptance. The package is pinned to online.hoopcheck.app; the caller must independently verify Auth, MFA, frozen/deleting status, role, purchase intent and rate limits. Google authentication and provider scope not live tested. Acknowledgment, durable purchase ownership, token storage, RTDN, refresh, entitlement resolver and native Play bridge remain unimplemented. No environment or migration changes authorized.
