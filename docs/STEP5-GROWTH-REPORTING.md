# Step 5 growth reporting handoff

Owner-only /owner-hq/growth uses reviewed aggregate observations, not live event collection. Off unless HOOPCHECK_GROWTH_REPORT_ENABLED=true. Supply HOOPCHECK_GROWTH_REPORT_JSON only after data governance and independent review. Never put real user rows, identifiers, secrets, or raw logs in the payload. No activation or environment setting is authorized by this PR.

Required JSON keys: windowStart, windowEnd (canonical UTC midnights exactly seven days apart; end no later than now and at most seven days old), source (short nonidentifying reviewed label), coverage ("web_ios_android"), weeklyActiveUsers (nonnegative integer or null), rates (object containing only signup_conversion, day7_retention, paid_conversion, referral_conversion with integer numerator and denominator). Missing/unverified rates should be omitted. Source reviewer must independently verify deduplication across platforms, qualifying action, staff/fixture exclusion and cohort completeness; the parser only checks shape and recency. Rates need at least ten observations in each complementary cell. Small active cohorts (<20) are suppressed. Do not substitute existing web page views or last-seen counts for active accounts. Goal progress is capped at 100%, actual accepted count remains visible. No new tracking or provider calls. See STEP5-LAUNCH-PREPARATION.md for definitions.

Run node --test scripts/test-step5-growth.mjs with existing dependencies. The build invokes this test. The dashboard is preparation for reviewed observations, not an automated cross-platform telemetry pipeline.
