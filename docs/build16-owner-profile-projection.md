# Build 16 owner profile projection: review-only

The existing Build 8 review candidate uses an invoker profile reader. It cannot retrieve a protected column after its SELECT grant is revoked. The new candidate uses a no-argument, fixed-column private definer with an empty search path, auth.uid() ownership filter and verified-factor assurance gate; the public RPC is an invoker wrapper. No direct grants are widened. Includes fields used by current account, settings, dashboard and owner profile readers. Never returns birthdate, Stripe identity session ID, moderator ID or internal avatar moderation notes.

## Verification
The exact candidate body was executed in a rollback-only synthetic schema on production PostgreSQL, replacing its function/table/auth references with fixture equivalents. Fixture table structure derived from public.profiles without copying any rows. Two synthetic accounts had separate country values and moderation notices; the enrolled account had a verified factor. Direct SELECT was limited to id and username. Nine checks passed: guest denial, no JWT denial, enrolled AAL1 denial despite forged user_metadata, verified AAL2 own read, unenrolled AAL1 own-only read, direct country SELECT denial, anonymous authenticated claim denial, wrong-role claim denial, unknown assurance denial. The transaction rolled back. No deployed function, real user record, direct column grant or provider setting changed.

## Remaining gate
Do not apply the candidate or revoke remaining owner fields until genuine owner/nonowner JWT acceptance, verified-factor AAL1/AAL2 behavior, installed app compatibility and public directory query audit are complete. Existing public and native clients may still query raw current_country/avatar_url and owner-facing moderation_note/notification_preferences. Deployment of a new projection alone does not close those direct reads. Review the private schema execution ACL and function ownership before release. Test full owner profile load/edit and rollback path. No paid infrastructure or submission.
