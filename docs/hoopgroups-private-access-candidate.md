# HoopGroups private access candidate (review only)
This extends existing spaces, channels, membership, read receipts, replies, pending moderation and owner moderation. New visibility defaults to public for existing records; no widening of private rows when management is disabled. Private creation is atomic; no public intermediate group. Direct self-join into private communities is denied; recipient accepts a targeted invitation from an accepted contact. Only owners can manage membership, delegates and per-channel grants; moderators can review pending posts only in accessible channels. Member departure/removal cascades channel grants and moderator membership. Existing owner/global moderation remains. Private schema and caller-derived identity; no public service-role clients or provider calls.
Owner-only snapshot is bounded to 100 members, contacts, pending invitations and queue entries, 12 private channels. No claim that this is full roster paging. Actual schema and Realtime subscription/DELETE-event isolation, owner deletion/historical disposition, privacy export inclusion for new tables, and physical client acceptance are required before enabling. No live changes.
