# HoopCheck Data & Security Addendum — Template

> Attorney/privacy counsel review required.

A vendor or contractor that processes HoopCheck personal data must:

- Process data only for documented HoopCheck purposes.
- Use least-privilege access.
- Require MFA for administrative access.
- Encrypt data in transit and at rest where supported.
- Maintain appropriate endpoint and account security.
- Notify HoopCheck promptly of suspected security incidents.
- Assist with reasonable privacy/security requests.
- Not sell personal data.
- Not use HoopCheck data for unrelated model training, advertising or profiling without written authorization and legal review.
- Return/delete data at the end of the engagement where required.
- Use subprocessors only as authorized.
- Maintain reasonable logs and evidence needed for security investigations.
- Cooperate with incident response and legally required notifications.

The exact security standard, breach timeline, data location, subprocessor requirements and audit rights should be finalized by counsel based on the vendor and applicable law.
