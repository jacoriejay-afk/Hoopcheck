# Video Story technical inspection (review only)
The local/private worker now claims a staged asset under a five-minute durable fence, reads only its exact quarantine object, checks actual byte count and media type, uses ffprobe and a bounded complete FFmpeg decode to validate one video track and at most one audio track, then records an exact SHA-256, duration and dimensions. The acknowledgement rechecks the storage catalog ID and version; expired fences and changed objects are rejected. Default database and process switches are off. No provider credentials, publication, playback signing, destructive cleanup or external moderation calls are included. Production and hosted database operation remain prohibited by the QA directive. The runtime must be non-root, isolated from external networks except the approved isolated storage origin, with resource limits and patched FFmpeg. Actual-schema storage permissions, signed-upload compatibility, immutable object identity, full visual/audio moderation, audience policy, publication and cleanup are separate outstanding requirements. This worker verifies technical media integrity, not content safety.
