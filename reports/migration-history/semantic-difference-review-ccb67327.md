## Offline PostgreSQL 17 syntax-tree comparison
The new script parses all 221 recorded statement arrays and all 218 repository files using a PostgreSQL 17-compatible pglast parser (v7 series; verify the installed major at runtime). It strips only numeric source-position metadata, retains literal contents and statement order, compares AST hashes, and reports unique/ambiguous/missing/parse-error candidates. SQL and PL/pgSQL function bodies remain literal strings where PostgreSQL's raw AST represents them as such; no normalization of procedural bodies is claimed. This can identify matches for unmapped records without filename assumptions. It never executes SQL, connects to a database, prints raw SQL, or authorizes replay. An AST match is not a runtime or data-effect equivalence proof.

Use a reviewed, pinned PG17 parser in an isolated environment; no dependencies installed in production or CI by this change. The local environment lacks pglast; parser self-tests and full comparison have not run. See https://pglast.readthedocs.io/en/v7/ for parser API. Run `python3 scripts/compare-migration-history-pg17.py --self-test` before comparison.
